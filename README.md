# Задача об обедающих философах

## Описание задачи

В задаче участвуют пять философов, которые сидят за круглым столом. У каждого философа есть блюдо со спагетти. Спагетти настолько скользкие, что для еды каждому философу требуется **две вилки**: левая и правая, расположенные рядом с его блюдом.  

Философы чередуют **приём пищи** и **размышления** (каждое действие занимает некоторое время). Философы могут оставаться голодными бесконечно, но необходимо **избежать ситуации, когда все философы голодны и ни один не может взять обе вилки** (т.е. избежать дедлока).

---

## Реализации

В проекте реализованы два варианта симуляции:

### 1. Корректная реализация

- Философы берут вилки в порядке, который **не приводит к дедлоку**.  
- Для одного философа (например, `philosopher-1`) последовательность захвата вилок изменена, чтобы разорвать циклическую зависимость.  
- Потоки философов выполняются параллельно, каждый философ ограничен **количеством приёмов пищи**, после чего поток завершается.  
- Программа **автоматически завершает работу**, когда все философы поели.

### 2. Реализация с дедлоком

- Философы берут вилки **в одном и том же порядке**, что может привести к ситуации дедлока:  
  все философы захватили одну вилку и ждут вторую, **никто не может есть**.  
- Данная версия используется для демонстрации дедлока и неправильного управления ресурсами.  
- Потоки не ограничены по количеству циклов и могут зависнуть.
